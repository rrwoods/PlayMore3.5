[COMMON] Weapon properties are complicated

The controller needs to be able to report what modes a weapon has (melee, second melee, thrown, projectile) so that the UI can use that information to allow the user to apply different properties to the various modes.  As of this writing it only applies the properties to the melee mode.

Also, allow adding weapon properties to shield bashes and armor spikes.
