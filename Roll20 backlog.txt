Beyond20 is a browser extension that accomplishes this by finding the chat box and send message button and using javascript to post the roll message.  Could accomplish the chat-sending with TamperMonkey.

https://github.com/kakaroto/Beyond20/blob/master/src/roll20/content-script.js#L33

However, Beyond20 is in the position of communicating information between two browser apps (D&D Beyond + Roll20), making a browser extension the ideal form.  Can you write a browser extension that receives information from outside the browser?



... the "cheap" way out here is to have the program just put text in your clipboard you can paste into the roll20 chat box.

--- MILESTONES ------------------------

Make a d20 roll happen in roll20 by clicking a "roll" button

Report the result back on a label in the lower right corner

===

Allow for rolling of d20 stats:
- create a "Roll" button that is normally hidden
- Label_MouseOver on labels with d20 stats: show the roll button, and position it exactly adjacent to the label being hovered
- Form_MouseOver: hide the button

===

Allow for rolling of attacks.  clicking the roll button for an attack should:
- Make the attack roll
- If it's a critical threat, make the critical confirmation roll
- Make the damage roll
- If it was a critical threat, roll the extra critical damage (!)
