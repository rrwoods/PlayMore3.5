Round system:

the controller should store:
- The current day (how?  just a weekday number 0-6?  a full date?)
- The number of rounds elapsed in the current day
- What round the current encounter started on (you're *always* in an encounter.)
- Whether you're in combat

For specifying the flow of time, the controller will have:
- StartCombat, which marks the current round as the start of the current encounter and sets the combat flag; also, fully resets any actions that are per-encounter, and (probably) any that are per-minute or shorter
- EndCombat, which is identical to above, but clears the combat flag
- NextRound, NextMinute, NextHour, and NextDay
- ActivateToggle, which sets a Toggle, but knows to clear it after a specified number of rounds have passed

For reporting what round it is, if we're in-combat it should report "round X of combat", and otherwise it should report what day and time it is.

When the UI advances time it needs to refresh effects!
