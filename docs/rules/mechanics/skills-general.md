# Skills: Core Mechanics and Systems

## 1. Skill Checks and Resolution
- **Primary Source**: *Player's Handbook*, pp. 61–64
- **Skill Check Formula**:
  $$\text{Check Result} = 1\text{d}20 + \text{Skill Modifier}$$
  $$\text{Skill Modifier} = \text{Skill Ranks} + \text{Key Ability Modifier} + \text{Miscellaneous Modifiers}$$
- **Miscellaneous Modifiers**: Include racial bonuses, armor check penalties, feat bonuses, and synergy bonuses.
- **Natural Rolls**: A natural 20 is not an automatic success; a natural 1 is not an automatic failure.
- **Opposed Checks**:
  - Two or more creatures compare check results; highest result succeeds.
  - **Ties**: Broken by the contestant with the higher skill modifier. If still tied, re-roll.
- **Untrained Skill Checks**:
  - Allowed for skills without the Trained Only restriction.
  - Formula: $1\text{d}20 + \text{Key Ability Modifier} + \text{Miscellaneous Modifiers}$ (with 0 ranks).
  - Trained Only skills cannot be attempted untrained.
- **Circumstance Modifiers**:
  - Favorable conditions: $+2$ circumstance bonus to skill modifier (or $-2$ to DC).
  - Unfavorable conditions: $-2$ circumstance penalty to skill modifier (or $+2$ to DC).
- **Retries (Trying Again)**:
  - Permitted indefinitely if a failed attempt carries no penalty or irreversible state change.
  - Prohibited or restricted if failure incurs damage, triggers traps, alters attitudes, or expends resources.

## 2. Skill Acquisition and Advancement
- **Primary Source**: *Player's Handbook*, pp. 61–63
- **Base Skill Points per Level**:
  | Class | Base Points / Level |
  | :--- | :---: |
  | Barbarian | 4 |
  | Bard | 6 |
  | Cleric | 2 |
  | Druid | 4 |
  | Fighter | 2 |
  | Monk | 4 |
  | Paladin | 2 |
  | Ranger | 6 |
  | Rogue | 8 |
  | Sorcerer | 2 |
  | Wizard | 2 |
- **1st-Level Skill Points**:
  $$\text{Points}_{\text{1st}} = (\text{Base Class Points} + \text{INT mod}) \times 4 + (\text{Human Bonus: } 4)$$
  - Minimum total gained at 1st level is 4 points.
- **Higher-Level Skill Points**:
  $$\text{Points}_{\text{Level}} = \text{Base Class Points} + \text{INT mod} + (\text{Human Bonus: } 1)$$
  - Minimum total gained per level advancement is 1 point, regardless of Intelligence penalties.
- **Intelligence Tracking**: Calculated using permanent Intelligence score (including inherent bonuses and drain); temporary enhancements and damage do not modify skill points gained.
- **Spending Points and Rank Caps**:
  - **Class Skills**: 1 skill point buys 1 rank.
    $$\text{Max Class Rank} = \text{Character Level} + 3$$
  - **Cross-Class Skills**: 1 skill point buys $1/2$ rank.
    $$\text{Max Cross-Class Rank} = \frac{\text{Character Level} + 3}{2} \quad (\text{exact half; not rounded})$$
  - **Multiclass Max Ranks**: If a skill is a class skill for *any* class a character possesses, the rank cap uses the class skill formula ($\text{Character Level} + 3$), but buying ranks costs 1 point per $1/2$ rank if not on the class list advancing at that level.
  - **Maxing Out**: Investing 1 point per level maintains a maxed-out skill.
  - **Unspent Points**: Skill points cannot be saved across levels; all points must be spent when advancing.

## 3. Checks Without Rolls and Cooperative Checks
- **Primary Source**: *Player's Handbook*, p. 65
- **Taking 10**:
  - Available when a character is not threatened, distracted, or in immediate combat danger.
  - Check result equals $10 + \text{Skill Modifier}$.
- **Taking 20**:
  - Available when a character has sufficient time ($20\times$ normal action time), faces no danger or distraction, and the task carries no penalty for failure.
  - Check result equals $20 + \text{Skill Modifier}$.
  - Assumes repeated failures before ultimate success; cannot be used if failure imposes a penalty.
- **Aid Another**:
  - Standard action to assist an ally attempting a skill check.
  - Helper makes a check against DC 10. Success grants a $+2$ circumstance bonus to the lead character's check.
  - Cannot take 10 on an Aid Another check.
  - Character must be capable of attempting the task independently to provide aid.

## 4. Skill Synergy
- **Primary Source**: *Player's Handbook*, p. 66
- **Synergy Rule**: Having 5 or more ranks in a prerequisite skill grants a $+2$ synergy bonus on checks with related skills or abilities.
- **Synergy Pairings (Table 4–5)**:
  | Prerequisite (5+ Ranks) | Synergistic Check Granted (+2 Bonus) |
  | :--- | :--- |
  | Bluff | Diplomacy checks |
  | Bluff | Disguise checks (to act in character) |
  | Bluff | Intimidate checks |
  | Bluff | Sleight of Hand checks |
  | Craft | Related Appraise checks |
  | Decipher Script | Use Magic Device checks involving scrolls |
  | Escape Artist | Use Rope checks involving bindings |
  | Handle Animal | Ride checks |
  | Handle Animal | Wild empathy checks (class feature) |
  | Jump | Tumble checks |
  | Knowledge (arcana) | Spellcraft checks |
  | Knowledge (arch & eng) | Search checks (secret doors and compartments) |
  | Knowledge (dungeoneering) | Survival checks (underground) |
  | Knowledge (geography) | Survival checks (avoid hazards / getting lost) |
  | Knowledge (history) | Bardic knowledge checks (class feature) |
  | Knowledge (local) | Gather Information checks |
  | Knowledge (nature) | Survival checks (aboveground natural) |
  | Knowledge (nobility & royalty) | Diplomacy checks |

## 5. Ability Checks
- **Primary Source**: *Player's Handbook*, p. 66
- **Formula**: $1\text{d}20 + \text{Ability Modifier}$.
- **Application**: Used when an action tests a raw physical or mental attribute without an applicable skill.
- **Straight Contests**: Straight tests of capability without luck (e.g., pure weight or arm wrestling between known scores) are won by the higher score without a roll.
